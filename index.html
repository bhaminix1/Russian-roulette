THE ODDS, PLAINLY

The cylinder always has exactly six chambers. Each round picks one chamber, and every chamber has the same 1-in-6 chance (≈16.67%).

Each question sits in exactly one chamber, so every question has a 1-in-6 chance per round, no matter how many questions you enter. Unused chambers are empty, and an empty result is a real outcome: a Lucky Escape. It is never rerolled.

The chamber is chosen with crypto.getRandomValues() and rejection sampling (no modulo bias) before the animation starts. The spin only reveals that result.
